## 1. 产品概述

智题云校（ZhiTi Cloud）是一款面向多学校、多教师协作的在线大型题库与讲义管理平台。系统以"学校池"为单位实现数据隔离，每位教师可独立建题、组讲义、追踪学生使用情况，借助 AI 自动识别题目知识点与章节，并提供联网分析他人标注能力，最终形成"题目—讲义—学生"的闭环教学辅助系统。

- **目标用户**：中学/高校教师、教研组、个别辅导教师
- **核心价值**：通过 AI 大幅降低题目结构化成本，让教师专注教学设计而非录入工作
- **市场定位**：K12 与高校通用题库 SaaS，支持学校采购与教师自助使用双模式

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|---------|----------|
| 平台管理员 | 后台创建 | 管理所有学校、审核学校资质、全局数据统计 |
| 学校管理员 | 教师认证升级 | 管理本校池、审核教师加入、维护本校班级学生 |
| 教师 | 邮箱/手机号注册 | 申请加入学校、自建题库与讲义、管理个人试题篮与学生 |
| 学生 | 教师录入或学校导入 | 接收讲义作业、查看题目、回传答题数据 |

### 2.2 功能模块

1. **认证与学校入口**：教师注册、学校认证加入、学校池切换
2. **工作台首页**：数据概览、待办、快捷入口、最近讲义
3. **题库管理**：题目列表、筛选、详情、批量操作
4. **文档导入与 AI 识别**：上传文档、AI 结构化识别、人工确认、入库
5. **讲义库管理**：讲义列表、属性筛选、版本管理
6. **讲义编辑器**：可视化编辑、多源添加题目、AI 生成知识点
7. **知识树浏览器**：章节与知识点的树形展开、复选筛选
8. **班级与学生管理**：本校班级维护、个人小教学班组建
9. **试题篮管理**：多篮子并行、跨篮子组讲义
10. **学生使用分析**：题目使用次数、关联学生答题情况

## 3. 核心流程

### 3.1 教师注册到建校流程

教师注册账号 → 搜索学校 → 提交认证材料 → 学校管理员审核 → 加入学校池 → 开始使用

```mermaid
flowchart TD
    "教师注册账号" --> "搜索目标学校"
    "搜索目标学校" --> "提交认证材料(工号/证明)"
    "提交认证材料(工号/证明)" --> "学校管理员审核"
    "学校管理员审核" -->|"通过"| "加入学校池"
    "学校管理员审核" -->|"拒绝"| "重新提交或选择其他学校"
    "加入学校池" --> "进入工作台"
```

### 3.2 文档导入与 AI 识别流程

教师上传文档 → 系统保留原文存入讲义库 → AI 识别题目/答案/解析/知识点 → 联网分析同类题目标注 → 教师确认或重新识别 → 入库题库

```mermaid
flowchart TD
    "上传文档(Word/PDF/MD)" --> "原文结构化存入讲义库"
    "原文结构化存入讲义库" --> "AI 识别题目与知识点"
    "AI 识别题目与知识点" --> "联网分析同类题目标注"
    "联网分析同类题目标注" --> "教师逐题确认"
    "教师逐题确认" -->|"确认"| "AI 识别章节与知识点"
    "教师逐题确认" -->|"重新识别"| "AI 识别题目与知识点"
    "AI 识别章节与知识点" --> "题目入题库"
    "题目入题库" --> "更新知识树"
```

### 3.3 讲义编辑流程

新建讲义 → 设置属性(章节/年级/学年/班级) → 从试题篮/题库/讲义添加题目 → AI 生成知识点讲解 → 保存发布

```mermaid

    "设置属性(章节/年级/学年)" --> "勾选适用班级或学生"
    "勾选适用班级或学生" --> "添加题目来源"

    "选择篮子中的题目" --> "AI 生成知识点讲解(可选)"
    "筛选并选择题目" --> "AI 生成知识点讲解(可选)"
    "选择讲义并复制题目" --> "AI 生成知识点讲解(可选)"
    "AI 生成知识点讲解(可选)" --> "保存并发布讲义"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深墨蓝 (#0B2545) + 学术金 (#D4A24C) 作为强调色，传达严谨学术感
- **辅助色**：浅雾灰 (#F5F7FA) 背景 + 纸张白 (#FFFFFF) 卡片，配以淡青 (#7FB3D5) 次级强调
- **按钮风格**：主按钮采用实色填充带细微阴影、圆角 6px；次级按钮采用描边样式
- **字体方案**：标题用思源宋体 (Noto Serif SC) 体现学术感，正文用思源黑体 (Noto Sans SC) 保证可读性，等宽数据用 JetBrains Mono
- **布局风格**：左侧固定侧栏导航 + 右侧主内容区，卡片化信息组织，知识树采用树形缩进
- **图标风格**：线性图标 (Lucide React)，统一 1.5px 描边，与学术克制风格一致
- **动效**：页面切换淡入、卡片 hover 微抬升、树形展开平滑过渡、AI 识别时打字机效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 登录注册页 | 注册卡片 | 左右分屏，左侧深墨蓝渐变背景配学术插画，右侧白色表单卡片，金色主按钮 |
| 工作台首页 | 数据卡片 | 4 列统计卡片带图标，渐变数字大字号，下方双栏待办与快捷入口 |
| 题库管理页 | 筛选面板 | 左侧 280px 知识树折叠面板，右侧题目卡片网格 2 列，顶部搜索栏 |
| 文档导入页 | AI 识别面板 | 三栏布局：原文预览、识别结果、确认操作，识别进度条带百分比 |
| 讲义编辑器 | 编辑主区 | 左侧大纲树，中间富文本编辑区，右侧属性面板与题目库切换 |
| 知识树浏览器 | 树形视图 | 全屏树形展开，节点前复选框，右侧抽屉显示关联题目 |
| 班级学生管理页 | 列表视图 | 顶部标签切换"本校班级/个人教学班"，下方表格+操作列 |
| 试题篮管理页 | 篮子网格 | 篮子卡片网格 3 列，点击进入篮子详情列表视图 |

### 4.3 响应式设计

- **桌面优先**：1280px 及以上为最佳体验，1920px 下采用更宽内容区
- **平板适配**：768px-1280px 侧栏折叠为图标、卡片单列、表格转为卡片视图
- **移动端**：仅保留工作台、题库浏览、试题篮查看等只读功能，编辑类操作引导至桌面端

### 4.4 3D 场景指引

本项目不涉及 3D 场景。

## 5. 数据与权限

### 5.1 数据隔离

- 学校池：题库、班级、本校学生数据按学校隔离
- 教师私有：个人题库子集、个人试题篮、个人教学班、个人讲义草稿
- 共享数据：本校班级与学生信息、本校公共题库（教师可设私有/共享）

### 5.2 权限矩阵

| 资源 | 教师本人 | 同校其他教师 | 学校管理员 | 平台管理员 |
|------|---------|-------------|-----------|-----------|
| 个人题库 | 完全控制 | 不可见 | 不可见 | 可审计 |
| 共享题库 | 读取使用 | 读取使用 | 完全控制 | 可审计 |
| 本校班级 | 读取使用 | 读取使用 | 完全控制 | 可审计 |
| 个人教学班 | 完全控制 | 不可见 | 不可见 | 可审计 |
| 个人讲义 | 完全控制 | 不可见 | 不可见 | 可审计 |
